# EnKeyBoard

个人使用的 macOS 英文输入法。支持前缀补全、有序跳跃字母匹配、横向候选和离线选词学习。

当前版本 0.2.3，面向本机 Apple Silicon。构建产物位于 `dist/EnKeyBoard.app`，用户安装路径为 `~/Library/Input Methods/EnKeyBoard.app`。本版本已编译、签名并安装，实际按键行为待用户验收。

## 开始使用

1. 系统设置 → 键盘 → 文本输入 → 编辑，确认已添加 **EnKeyBoard**。若没有显示，添加英文分类中的 EnKeyBoard。0.2.3 将带子模式的结构改为单一输入法，升级后请先保存工作，注销并重新登录一次，让系统界面重载注册结构，再进行按键验收。
2. 将“按 Fn/🌐 键”设置为“更改输入源”。Fn 在已启用的输入源之间切换。
3. 启用系统“使用中/英键切换到 ABC 及从 ABC 切回”选项，并保留 ABC 输入源。旧版曾建议关闭这个选项，请恢复为开启。
4. 物理“中/英”键（Caps Lock 键位）完全交给 macOS 原生机制：轻按应切换输入源，不应锁定大写。选中 EnKeyBoard 后在它与 ABC 之间切换；Fn 或菜单选回其他输入法后，在该输入法与 ABC 之间切换。系统原有的长按行为保持不变。

系统自带的拼音输入法也完全使用 macOS 原生中/英切换。Fn 从 EnKeyBoard 选回系统拼音后，轻按中/英应在系统拼音与 ABC 之间往返；选回微信输入法后则在微信输入法与 ABC 之间往返。

0.2.2 已删除全局 Caps Lock 监听、配对记忆和延迟切换代码，不需要辅助功能授权。设置中可打开系统键盘设置；输入法菜单“切换到系统英文”仅在用户主动点击时选择 ABC/U.S.。没有登录项、LaunchAgent、键盘映射或独立切换组件。

0.2.1、0.2.2 的 ASCII=false 核对未解决用户的切换异常。进一步读取系统原生切换属性发现：父容器开启了原生中/英切换，但可选子模式仍为关闭。0.2.3 删除子模式，直接注册一个可选的 EnKeyBoard；实际属性已核对为 ASCII=false、nativeCapsSwitch=true。安装同时检查这两项以及只有一个启用的本项目输入源。注册属性不能代替按键验收。排查记录见 [输入源修复说明](docs/INPUT_SOURCE_REPAIR.md)。

## 输入与选词

| 操作 | 效果 |
|---|---|
| `cust` | 4 个字母不显示候选 |
| `custo` | 满 5 个字母，候选中可见 `customer` |
| `itntnal` | 有序跳字母，候选中可见 `international` |
| 空格 | 提交当前候选并加一个空格；无候选则提交原始字母 |
| 数字 1–5 | 提交当前页对应的候选，不自动加空格 |
| ↑ / ↓ | 切换选中候选 |
| Page Up / Page Down | 翻页；Mac 键盘通常为 Fn+↑ / Fn+↓ |
| Enter | 提交当前候选页第一项，不加空格；无候选时提交原文；没有待输入文字时正常换行 |
| Esc | 保留原始字母并退出候选 |
| Backspace | 删除正在输入的最后一个字符 |
| ← / → / Tab | 先提交原文，再交给应用处理 |
| 逗号、句号等 | 提交当前候选，再输入标点 |
| 撇号、连字符 | 可继续输入 `don't`、`well-known` 等词 |

所有候选统一在输入至少 5 个英文字母后显示，撇号和连字符不计入门槛。完整词优先，随后是前缀匹配，再是跳跃匹配。跳跃匹配要求首字母相同且字母顺序正确，不做错字、颠倒字母或任意缩写纠正。前缀词可能挤占第一页，例如 `profl` 优先出现 `profligate`，可用 `profsl` 更明确地输入 `professional`。

候选左边缘与插入光标对齐，位于文字行正下方，显示期间持续更新光标位置。下方空间不足时移动到光标上方防止溢出；客户端没有提供有效光标坐标时隐藏候选，不再放到屏幕中央。

## 设置与个人词库

从系统输入法菜单打开“设置与个人词库…”。支持启停本机学习、打开系统键盘设置、手动添加词、导入 UTF-8 词表以及清空学习记录。

词表每行一个英文词，也接受 TSV/CSV 的第一列；允许撇号和连字符，不接受空格短语。`#` 开头的行视为注释。错误的行会使本次导入停止，不会部分写入。

只记录明确提交的候选词及次数，不记录完整句子；陌生词不会自动加入词库。数据在 `~/Library/Application Support/EnKeyBoard/learning.sqlite`，不联网、不上传。清空学习记录保留个人词。

## 构建、安装与预览

只需 Apple Command Line Tools 中的 Swift 工具链，不必安装完整 Xcode；没有第三方运行时依赖。

```sh
./scripts/build.sh
./scripts/install.sh
open dist/EnKeyBoard.app --args --preview
```

预览窗口只验证词库与候选外观；它不能代替系统输入法按键和跨应用验证。应用使用本机临时签名，仅供个人开发使用，未做公开分发公证。

开发检查（按用户需要自行运行）：

```sh
./scripts/check.sh
.build/release/enkeyboard-cli custo
.build/release/enkeyboard-cli itntnal
```

手动验收见 [TESTING.md](TESTING.md)，技术共识见 [docs/DESIGN.md](docs/DESIGN.md)。

## 移除

运行 `./scripts/uninstall.sh`，阅读提示并输入 `UNINSTALL`。这会删除个人词库和学习记录；需要保留时先复制数据目录。脚本先切离并禁用本项目输入源，再停止进程、注销应用、撤销本应用权限并删除应用、偏好、缓存和数据。不会改动其他输入法或全局键盘设置。

安装升级会保存最早可获得的输入源快照。旧版初装没有快照，本版本不能凭空还原第一次安装前的历史状态；你手动改变的系统设置也需手动恢复。系统可能保留输入源缓存、使用历史、诊断日志或权限列表缓存，需要注销重登录或手动清理权限条目。源码与 dist 构建产物保留。

因此本项目提供自身资源的清理卸载，不能宣称已验证系统逐字恢复为安装前状态。详见 [卸载范围与限制](docs/UNINSTALL.md)。

## 词库来源

内置 89,968 条美式英文词汇，以 ESDB/SCOWL US size 60、variant 1 的词形为基础，合并 SymSpell 提供的 Google Books Ngram 词频；未匹配到词频的词使用回退频次 1。默认排除专有名词、非 ASCII 词、短语及特殊类别；个人词可另行添加。

所有来源与许可位于 `Resources/Licenses/`，构建来源及哈希位于 `Resources/lexicon.provenance.json`。重新生成词库需要 ESDB 对应版本和词频输入文件，再运行 `scripts/generate_lexicon.py`；常规构建与使用均离线。
